# Schema Introspection

Schema Introspection is part of the Qubase Database Engineering workflow. This guide introduces the key concepts without assuming unsupported platform behavior.

## Key guidance

Review the source and target Database Schema before applying engineering changes.

## Before you continue

Keep names and changes consistent with the Database Schema conventions agreed for your Project.

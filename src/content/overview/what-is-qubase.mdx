# What is Qubase?

Qubase is a modern database design and engineering platform that enables individuals and teams to design, manage, and collaborate on database schemas through an intuitive visual interface.

Instead of relying only on handwritten SQL, Qubase provides an interactive ERD Canvas where database structures can be created, edited, and maintained visually while keeping SQL and DBML synchronized.

## Why Qubase?

Traditional database design often requires switching between multiple tools for modeling, SQL development, documentation, and collaboration.

Qubase brings these workflows together into a single platform, allowing teams to design databases more efficiently and maintain a single source of truth throughout the development process.

## Key capabilities

Qubase helps you:

- Design databases visually using an interactive ERD Canvas
- Create Conceptual, Logical, and Physical data models
- Synchronize visual diagrams with SQL and DBML
- Reverse engineer existing databases
- Generate database-specific SQL scripts
- Collaborate with teammates in shared Workspaces
- Track schema history and version changes
- Improve productivity with AI-assisted database engineering

## How Qubase works

A typical workflow looks like this:

```text
Create Workspace
        ↓
Create Project
        ↓
Create Database Schema
        ↓
Design Database
        ↓
Generate SQL / DBML
        ↓
Collaborate
        ↓
Deploy
```

## Who should use Qubase?

Qubase is designed for:

| User | Benefits |
| ---- | -------- |
| Database Designers | Build clear and maintainable database structures |
| Backend Developers | Generate schemas and SQL more efficiently |
| Full-stack Developers | Keep database design aligned with application development |
| Teams | Collaborate on shared database projects |
| Students | Learn database modeling through visual design |

## Why choose Qubase?

Compared to traditional database design workflows, Qubase offers:

- A visual-first design experience
- Real-time synchronization between diagrams and code
- Built-in collaboration
- Version history and change tracking
- AI-powered database engineering tools
- A centralized workspace for all database projects

> [!TIP]
> Qubase is designed to support the entire database development lifecycle—from initial design to collaboration and engineering.

# Platform Settings

Platform Settings is part of the Qubase Admin Guide workflow. This guide introduces the key concepts without assuming unsupported platform behavior.

## Key guidance

Apply Role-Based Access Control according to the responsibilities of each Workspace and Project member.

## Before you continue

Keep names and changes consistent with the Database Schema conventions agreed for your Project.

# Activity Logs

Activity Logs provide administrators with a chronological record of important platform events.

Reviewing activity logs helps administrators understand platform activity, monitor administrative actions, and investigate operational changes when necessary.

---

## Before you begin

Before accessing Activity Logs, ensure that you have:

- Administrator access
- Permission to view platform activity

> [!NOTE]
> Activity Logs are available only to authorized administrators.

---

## What are Activity Logs?

Activity Logs record important events that occur across the platform.

Depending on your platform configuration, logs may include:

- User activity
- Project activity
- Workspace activity
- Administrative actions
- Template management activity

The available log entries depend on your platform configuration.

---

## View activity logs

To review platform activity:

1. Sign in as an administrator.
2. Open the **Admin Dashboard**.
3. Navigate to **Activity Logs**.

The activity list displays recent platform events.

---

## Log information

Each activity log may include:

| Property | Description |
| -------- | ----------- |
| Timestamp | Date and time of the activity |
| User | User who performed the action |
| Activity | Description of the event |
| Resource | Related platform resource |
| Status | Result of the action (if applicable) |

---

## Review activity

Activity Logs help administrators:

- Monitor platform usage
- Review administrative actions
- Investigate recent changes
- Understand platform events

Reviewing logs regularly helps maintain operational visibility.

---

## Benefits

Activity Logs help administrators:

- Monitor important events
- Improve platform oversight
- Support operational reviews
- Maintain administrative transparency

---

## Best practices

- Review logs regularly.
- Investigate unexpected activity.
- Verify administrative changes before taking further action.
- Maintain appropriate access to activity records.

> [!TIP]
> Regularly reviewing Activity Logs helps administrators understand how the platform is being used and identify unusual activity more quickly.

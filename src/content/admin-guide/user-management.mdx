# User Management

User Management enables administrators to manage user accounts across the Qubase platform.

Administrators can review registered users, monitor account status, and perform administrative actions to help maintain a secure and well-organized platform.

---

## Before you begin

Before managing users, ensure that you have:

- Administrator access
- Permission to manage platform users

> [!NOTE]
> User Management is available only to administrators.

---

## What is User Management?

User Management provides centralized administration for platform users.

Depending on your administrator permissions, you may be able to:

- View registered users
- Search users
- Review user information
- Monitor account status
- Update user information
- Manage user access

Available actions depend on your platform configuration.

---

## View users

To view platform users:

1. Sign in as an administrator.
2. Open the **Admin Dashboard**.
3. Navigate to **User Management**.

The user list displays all registered platform users.

---

## User information

Each user record may include:

| Property | Description |
| -------- | ----------- |
| Display Name | User's public name |
| Email Address | Registered email |
| Account Status | Current account status |
| Joined Date | Date the account was created |
| Last Active | Most recent activity |

---

## Search users

Administrators can search for users to quickly locate a specific account.

Search may support:

- Display Name
- Email Address

The available search options depend on your platform configuration.

---

## Manage users

Depending on your permissions, you may be able to:

- View user details
- Update user information
- Manage account access
- Review user activity

Administrative actions affect only the selected user account.

---

## Benefits

User Management helps administrators:

- Organize platform users
- Maintain account security
- Monitor platform activity
- Support user management tasks

---

## Best practices

- Review user accounts regularly.
- Verify user information before making changes.
- Grant access only when appropriate.
- Remove unnecessary access promptly.

> [!TIP]
> Regularly reviewing user accounts helps maintain platform security and organization.

# Template Management

Template Management allows administrators to maintain the built-in database templates provided by Qubase.

Administrators can organize templates, update template information, and ensure that users have access to accurate and well-structured database templates.

Proper template management helps users start new projects quickly while maintaining consistent database design standards.

---

## Before you begin

Before managing templates, ensure that you have:

- Administrator access
- Permission to manage platform templates

> [!NOTE]
> Template Management is available only to platform administrators.

---

## What is Template Management?

Template Management provides centralized administration for built-in database templates.

Depending on your administrator permissions, you may be able to:

- View available templates
- Create new templates
- Update existing templates
- Remove templates
- Organize template categories

Available actions depend on your platform configuration.

---

## View templates

To manage templates:

1. Sign in as an administrator.
2. Open the **Admin Dashboard**.
3. Navigate to **Template Management**.

The template list displays all available built-in database templates.

---

## Template information

Each template may include:

| Property | Description |
| -------- | ----------- |
| Name | Template name |
| Category | Business domain |
| Description | Template overview |
| Database Type | Supported database structure |
| Last Updated | Most recent modification |

---

## Manage templates

Depending on your permissions, you may be able to:

- Create new templates
- Update template information
- Modify template content
- Delete templates
- Organize template categories

Changes become available to users after the template is published or updated.

---

## Benefits

Template Management helps administrators:

- Maintain high-quality templates
- Standardize database design
- Improve user productivity
- Keep template content up to date

---

## Best practices

- Review templates regularly.
- Keep template descriptions accurate.
- Remove outdated templates.
- Organize templates using clear categories.
- Test templates before publishing updates.

> [!TIP]
> Well-maintained templates help users begin new projects more efficiently and consistently.

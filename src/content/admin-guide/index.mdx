# Admin Guide

The Admin Guide provides documentation for administrators responsible for managing the Qubase platform.

Administrators can manage users, maintain database templates, monitor platform activity, and configure platform settings to support a secure and reliable environment.

This guide is intended for platform administrators and is not required for standard project members.

---

## What is the Admin Guide?

The Admin Guide covers administrative features available within Qubase.

Depending on your administrator permissions, you may be able to:

- Manage users
- Manage database templates
- Review platform activity
- Configure platform settings

Administrative features help maintain the platform and support all users.

## Best practices

- Review platform activity regularly.
- Assign administrative access carefully.
- Verify changes before saving.
- Keep platform settings organized.

> [!TIP]
> Administrative access should be granted only to trusted users who are responsible for maintaining the platform.

# Collaboration

Collaboration enables teams to design, review, and manage database schemas together in a shared workspace.

Instead of working individually, Qubase provides collaborative features that allow multiple members to contribute to the same project while maintaining organization, communication, and version history.

Whether you're working with developers, database administrators, or system analysts, Collaboration helps keep everyone aligned throughout the database engineering process.

---

## What is Collaboration?

Collaboration allows multiple users to work together on shared database projects.

Depending on your permissions, you can:

- Create Workspaces
- Manage Projects
- Invite team members
- Assign member roles
- Collaborate in real time
- Leave comments
- Receive notifications
- Review version history

## Features included

The Collaboration module includes:

| Feature | Description |
| ------- | ----------- |
| Workspaces | Organize projects for teams |
| Projects | Store and manage database schemas |
| Invite Members | Add collaborators to a workspace |
| Project Members | Manage member access and permissions |
| Real-Time Collaboration | Work together simultaneously |
| Comments & Mentions | Discuss database designs |
| Notifications | Stay informed about project activity |
| Version History | Review previous schema changes |

---

## Benefits

Collaboration helps teams:

- Work together efficiently
- Keep database projects organized
- Reduce communication gaps
- Track important changes
- Review database designs together
- Improve productivity

---

## Best practices

- Organize related projects into dedicated workspaces.
- Assign appropriate permissions to team members.
- Review important schema changes before implementation.
- Use comments to discuss design decisions.
- Check version history before restoring previous work.

> [!TIP]
> Collaboration works best when team members follow consistent naming conventions and review database changes regularly.

# Invite Members

Invite Members allows you to add collaborators to a Workspace or Project so they can participate in database design, engineering, and review activities.

Each invited member receives access based on the role and permissions assigned by the workspace or project owner.

---

## Before you begin

Before inviting members, ensure that you have:

- Created a Workspace
- Created a Project
- Permission to manage members

> [!NOTE]
> Only users with the required permissions can invite new members.

---

## Why invite members?

Inviting members allows your team to:

- Collaborate on database schemas
- Review database designs
- Contribute to AI Engineering workflows
- Participate in project discussions
- Share responsibilities across the project

---

## Invite a member

To invite a member:

1. Open a Workspace or Project.
2. Navigate to **Members**.
3. Select **Invite Member**.
4. Enter the user's email address.
5. Choose a role.
6. Send the invitation.

The invited user receives an invitation to join the Workspace or Project.

---

## Invitation information

Each invitation includes:

| Field | Description |
| ------ | ----------- |
| Email | User to be invited |
| Role | Assigned permission level |
| Status | Pending or Accepted |
| Invited By | User who sent the invitation |
| Invitation Date | Date the invitation was created |

---

## Invitation status

An invitation can have one of the following statuses:

| Status | Description |
| ------ | ----------- |
| Pending | Invitation has been sent but not accepted |
| Accepted | User has joined successfully |
| Expired | Invitation is no longer valid |
| Cancelled | Invitation has been withdrawn |

---

## Managing invitations

Depending on your permissions, you can:

- Resend invitations
- Cancel pending invitations
- View invitation history
- Monitor invitation status

---

## Best practices

- Invite only users who need access.
- Assign the appropriate role when inviting members.
- Remove expired invitations when no longer needed.
- Regularly review project membership.

> [!TIP]
> Assign the minimum level of access required for each collaborator to improve workspace security.

# Create Workspace

A Workspace is the primary collaboration space in Qubase. It allows you to organize projects, invite team members, and manage database development in a shared environment.

Every Project belongs to a single Workspace, making it easier to keep related database schemas, diagrams, and collaboration activities together.

## Before you begin

Before creating a Workspace, ensure that you:

- Have a verified Qubase account
- Are signed in to Qubase
- Have permission to create a new Workspace

> [!TIP]
> If you are working with a company or team, create one Workspace for each organization or department.

## Create a Workspace

1. Sign in to your Qubase account.
2. Open the **Dashboard**.
3. Select **Workspaces** from the navigation menu.
4. Click **New Workspace**.
5. Enter the required information.

| Field | Description |
| ------ | ----------- |
| Workspace Name | A unique name for your Workspace |
| Description | A short summary of the Workspace purpose *(optional)* |
| Workspace Icon | Optional icon to help identify the Workspace |

6. Review the information.
7. Click **Create Workspace**.

## Workspace roles

When you create a Workspace, you automatically become the **Workspace Owner**.

The Workspace Owner can:

- Manage Workspace settings
- Invite or remove members
- Create and manage Projects
- Assign member permissions
- Manage collaboration activities

## What happens next?

After creating your Workspace, you can:

- Create your first Project
- Invite team members
- Start designing database schemas
- Organize multiple projects in one place
- Manage collaboration permissions

## Best practices

- Use a clear and meaningful Workspace name.
- Create separate Workspaces for different organizations or clients.
- Invite only the members who need access.
- Keep Workspace settings updated as your team grows.

## Troubleshooting

### Workspace name already exists

Choose another name that better identifies your organization or project.

### I can't create a Workspace

Make sure you are signed in and your account has been verified.
